About the Project

The Sentiment Analysis API is a deep-learning project built to classify product reviews and analyze customer sentiment in real-time. It leverages a custom-trained PyTorch Long Short-Term Memory (LSTM) Neural Network, offering both single-inference and batch-processing capabilities.

How to Use the API

Testing single reviews or bulk CSV files can be initiated from the Home dashboard.
